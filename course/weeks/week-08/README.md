# Week 8 — Polish, GitHub, Demo, Enhance Later

**Milestone:** A demoable BASE app on GitHub with README, clear Enhance Later backlog, and a student who can narrate the full data flow.

No new architecture. No new entities. Polish + communicate + ship.

---

## Why this week exists

```text
Weeks 1–7: build the spine
Week 8: make it presentable and ownable after the course
```

Trainer line:

> “Done means demoable, documented, and honest about what comes next — not endless features.”

## What is explicitly out of scope

- Payments, SMS, AI, GPS, multi-branch  
- Mobile apps, microservices, Docker-for-prod deep dives  
- Redesigning schema mid-week  
- Adding a third role  

If a student finishes early: deepen debugging notes, write tests lightly, or improve README — **not** Enhance Later builds.
