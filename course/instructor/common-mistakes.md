# Common Mistakes (and corrections)

## 1. “The screen is the app”

**Correction:** Screenshot cannot send a message. Frontend is the waiter, not the whole restaurant.

## 2. Students want to code on Day 1

**Correction:** “We will code soon. If we don’t know the problem, coding is typing without direction.”

## 3. Building the full Fix-My-Ride vision in week 2

**Correction:** Point to BASE vs POSTPONE in FIX-MY-RIDE.md. Write extras on Enhance Later.

## 4. Rules only in React (not in backend)

**Correction:** Frontend checks are helpful UX; **real rules must live on the server**. Demo bypassing the UI with /docs.

## 5. Skipping PostgreSQL because mock data “works”

**Correction:** Close the app / restart server — mock and memory disappear. Persistence is a base feature.

## 6. Copy-paste without explaining

**Correction:** Ask: “What enters this function? What comes out? Which file owns this?”

## 7. Database = Excel

**Correction:** Similar idea (rows/columns), but software databases have keys, relationships, and controlled access.

## 8. One student dominates

**Correction:** Pair work; ask quieter students: “What happens after the button click?”

## 9. Introducing TypeScript early

**Correction:** This course is JavaScript → React. No TS unless project spec changes later.

## 10. Broken code left overnight

**Correction:** Always end on a runnable increment. If stuck, reset to last `increments/` checkpoint.

## 11. Auth over-engineering

**Correction:** Register, login, JWT, 2 roles. No OAuth social login, no refresh-token maze in BASE.

## 12. Different architecture per student

**Correction:** Same stack path for everyone. Only names change via Transfer Sheet.
